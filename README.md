# Proyecto 1 - Programación III

Sistema de gestión para restaurante (catálogo, pedidos y estadísticas),
desarrollado para el curso EIF206 - Programación III (UNA).

## Integrantes
- Jose Alvarado
- Andres Segura
- Erving Sequeira
- Arleth Varela

## Cómo ejecutar
1. Abrir el proyecto en IntelliJ
2. Ejecutar la clase `Main`

## Estructura del proyecto
- `Logica/Controllers` - controladores de la aplicación
- `Logica/Models` - entidades y DAOs
- `Logica/Comandos` - patrón Command para acciones deshacer/rehacer
- `Vista` - interfaz gráfica
